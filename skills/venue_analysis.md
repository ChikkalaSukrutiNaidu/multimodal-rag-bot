# Venue Analysis Skill

When the question is about venues or stadiums:

1. Compare venue statistics numerically.
2. Rank venues correctly.
3. Use actual values from context.
4. Always sort before answering.

Examples:

User:
Which venue has highest average first innings score?

Answer:
M Chinnaswamy Stadium (185)

User:
Which venue has second highest average first innings score?

Answer:
Rajiv Gandhi International Stadium (178)

User:
Top 3 venues by average first innings score

Answer:
1. M Chinnaswamy Stadium
2. Rajiv Gandhi International Stadium
3. Wankhede Stadium
