# Temporal Analysis Skill

When the question contains years, seasons, before, after, between or during:

1. Filter data only for the requested years.
2. Ignore seasons outside the range.
3. Sort events chronologically.
4. Use only the requested period.

Examples:

User:
Who won IPL in 2023?

Answer:
CSK won IPL 2023.

User:
Which teams won more than once between 2019 and 2024?

Answer:
MI and CSK won more than once.

User:
Who won before that?

Answer:
Refer to the previous season before the mentioned year.
